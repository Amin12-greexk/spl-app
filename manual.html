1. PENDAHULUAN

1.1 Tentang Sistem SPL

Sistem SPL (Surat Perintah Lembur) adalah aplikasi berbasis web yang dirancang untuk memfasilitasi proses pengajuan, persetujuan, dan pengelolaan data lembur karyawan PT Tunas Esta Indonesia. Sistem ini mengintegrasikan proses manual menjadi digital untuk meningkatkan efisiensi dan transparansi.

1.2 Tujuan Manual Book

Manual book ini disusun untuk memberikan panduan lengkap dan mendetail kepada seluruh pengguna sistem dalam mengoperasikan aplikasi SPL dengan benar dan efektif.

1.3 Pengguna Sistem

  • Staff: Karyawan yang mengajukan Surat Perintah Lembur
  • Manager: Pihak yang berwenang menyetujui atau menolak pengajuan SPL
  • HR (Human Resources): Administrator yang mengelola data dan laporan SPL secara keseluruhan

1.4 Spesifikasi Teknis

  • Platform: Web-Based (dapat diakses melalui browser)
  • Browser yang Didukung: Chrome, Firefox, Edge, Safari (Versi Terbaru)
  • Resolusi Layar: Optimal pada 1366x768 atau lebih tinggi
  • Keamanan: Protokol HTTPS (diperlukan untuk notifikasi push)

2. AKSES SISTEM

2.1 Registrasi Akun Baru

  1. Akses Halaman Registrasi: Buka URL sistem SPL dan klik "Daftar".
  2. Isi Formulir:
    • Nama Lengkap (sesuai identitas)
    • Email (nama@domain.com)
    • Password (min 8 karakter, kombinasi huruf/angka)
    • PIN (6 digit untuk verifikasi)
    • Departemen (IT, Production, QC, dll)
  3. Verifikasi: Role default adalah "STAFF". Hubungi admin untuk akses Manager/HR.

2.2 Login & Logout

Masukkan email dan password terdaftar pada halaman login. Jika lupa password, gunakan fitur "Lupa Password" untuk reset via email. Untuk keluar, klik profil di pojok kanan atas dan pilih "Logout".

3. PANDUAN UNTUK STAFF

3.1 Dashboard Staff

Dashboard menampilkan ringkasan aktivitas Anda:

  • Kartu Statistik: Total SPL, Menunggu, Disetujui, Ditolak.
  • Aksi Cepat: Tombol "Buat SPL Baru" dan "Riwayat SPL".
  • Aktivitas Terbaru: 3 pengajuan terakhir.

3.2 Membuat Pengajuan SPL

PERHATIAN:
Pengajuan SPL hanya dapat dilakukan sebelum batas waktu (Default: 16:30). Jika melewati batas waktu, sistem akan menolak otomatis.

Langkah-langkah Pengajuan:

  1. Klik tombol "Buat SPL Baru".
  2. Isi Informasi Dasar (Tanggal Lembur, Nama Proyek).
  3. Tentukan Waktu Lembur (Jam Mulai & Selesai). Sistem akan menghitung durasi otomatis.
  4. Isi Alasan Lembur dengan detail.
    Contoh yang baik: "Menyelesaikan laporan bulanan 15 sheet Excel untuk meeting direktur besok pagi."
  5. Tanda tangan pada Signature Pad digital.
  6. Klik "Ajukan SPL".

3.3 Status Pengajuan

Status Warna Keterangan
PENDING Kuning Menunggu review dari Manager. Dapat dihapus/dibatalkan.
APPROVED Hijau Disetujui Manager. Sudah final.
REJECTED Merah Ditolak oleh Manager. Lihat detail untuk alasan penolakan.

4. PANDUAN UNTUK MANAGER

4.1 Dashboard & Fitur Utama

Manager memiliki wewenang untuk mengatur operasional lembur tim:

  • Review SPL: Menyetujui atau menolak pengajuan.
  • Pengaturan Batas Waktu: Mengatur jam cut-off pengajuan (Default 16:30).

4.2 Proses Persetujuan (Approval)

  1. Akses menu "Persetujuan" atau klik panel notifikasi.
  2. Review detail pengajuan (Tanggal, Durasi, Alasan, Urgensi).
  3. Setujui: Klik tombol Hijau (Approve). Notifikasi terkirim ke staff.
  4. Tolak: Klik tombol Merah (Reject).
    • Wajib mengisi alasan penolakan pada kotak dialog yang muncul.
    • Berikan alasan yang konstruktif (misal: "Bisa diselesaikan jam kerja normal").
Tips: Rutin cek dashboard menjelang jam pulang kerja untuk memastikan tidak ada pengajuan yang tertahan.

5. PANDUAN UNTUK HR

5.1 Manajemen Data Laporan

HR memiliki akses penuh ke seluruh data SPL perusahaan ("Data & Laporan").

Filter Data:

  • Status: All, Pending, Approved, Rejected.
  • Periode: Bulan Ini, Bulan Lalu, Custom Date Range.

5.2 Export & Laporan

Terdapat 3 metode pengambilan data:

Metode Fungsi Utama Format
Export Excel Analisis data mendalam, pivot table, perhitungan payroll. .xlsx (Data lengkap 16 kolom)
Generate PDF Dokumen resmi/arsip fisik. Dilengkapi kop surat dan TTD digital. .pdf (Siap cetak A4)
Copy Table Sharing cepat via email/chat. Clipboard (Paste ke Excel/Word)

6. FITUR NOTIFIKASI

Sistem menggunakan Web Push Notification untuk update real-time.

Cara Mengaktifkan:

  1. Klik tombol "🔔 Aktifkan Notifikasi" di dashboard bawah.
  2. Browser akan memunculkan popup izin. Klik "Allow" atau "Izinkan".
  3. Jika sukses, status berubah menjadi "✅ Aktif".
Masalah Umum: Jika notifikasi tidak muncul, pastikan Anda tidak mengakses sistem dalam mode "Incognito" dan browser tidak memblokir notifikasi (Cek icon gembok di address bar).

7. TROUBLESHOOTING

Masalah Umum & Solusi

1. Error "Lewat Batas Waktu"

Sebab: Anda mengajukan setelah jam cut-off (misal 16:30).
Solusi: Temui Manager langsung untuk persetujuan manual.

2. Tanda Tangan Gagal Disimpan

Solusi: Pastikan goresan tanda tangan cukup jelas. Refresh halaman dan coba lagi.

3. Lupa Password

Solusi: Gunakan link "Lupa Password" di halaman login. Link reset akan dikirim ke email.

Kontak Support

Jika masalah berlanjut, hubungi tim IT:

  • Email: it@tunasesta.com
  • Ext: 123
  • Sertakan screenshot error saat melapor.
